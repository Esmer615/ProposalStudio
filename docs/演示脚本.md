# 5 分钟路演脚本 + Q&A — 乐园 AI 提案工作台

> 现场原则：**只讲取舍，不讲功能清单**；每个数字都能在页面上点开来源；评委改输入就当场改。
> 演示默认场景：上海乐高乐园 / 500 万 / 公交+地铁 / 2027-07-01 / 8 周 / 直客。
> 备用：若 API 异常，切到静态 fixture 模式或打开 `web/dist-export/index.html`（断网可跑）。

---

## 0:00–0:30 开场（问题）

“新云传媒的销售今天做一份户外提案：翻红豆查空车、凭经验定线路和折扣、手工拼 PPT，一套要好几天。客户当天要方案，单子就被竞对拿走。我们做的是一个本地工作台：**改一个滑杆，当天出提案**。”

打开 `http://127.0.0.1:8010`（工作台）。

## 0:30–1:30 默认方案：乐高 500 万

- 指顶部状态：**红豆 2027-07/08 快照、校验时间戳、数据版本**。
- 左侧：Campaign 假设书 H1–H7——“客户是谁、生意目标、campaign 目标、人群、时间预算、媒体范围、成功衡量”。
- 地图：乐高在金山枫泾、无地铁直达；公交做城市广度，地铁只买徐家汇/人民广场/静安寺/七宝/上海动物园等家庭出发枢纽。
- 方案表：39 辆公交 + 5 个地铁口；每个点有理由、库存、评分分解。
- 报价：刊例 692 万 → 68% 档（以实时为准）→ 折后 + 制作 = 总价；逐行分摊加总 == 总价。

**一句话**：“这不是把库存列出来，而是回答‘为什么买这些、为什么不买那些’。”

## 1:30–2:15 换场馆：迪士尼

- 场馆下拉切到“迪士尼”；图表/地图/假设书/配比全部变。
- 讲差异：迪士尼地铁 11 号线直达，地铁权重上升；乐高无地铁直达，公交权重更高。
- 点“为什么不是迪士尼站？”——竞品门口不买。

## 2:15–3:00 砍预算：500 → 200 万

- 拖预算滑杆到 200 万；250ms 后重算；旧结果保留，不白屏。
- 看弹性曲线：Reach 在 200 万已到 80%+，之后进入平台期；边际每万元曝光整体下降。
- 点“砍预算先砍谁”：先砍 A+ 铺底线路和弱枢纽地铁口，保留 S 公交 + 核心枢纽。
- 强调：**同一引擎**，不是三套方案。

## 3:00–3:45 地图交互：点开一个地铁口 + 锁定

- 点一个已选地铁口（如徐家汇/人民广场）：抽屉显示等级、库存、评分分解、选点理由、替代项；地图上无坐标的站不会伪造位置。
- 点“锁定”；方案重算并显示差异（多买/少买、预算变化）。
- 点“排除”另一个点；展示 LOCK/EXCLUDE 的真实联动。
- 说明：库存不足时返回 `LOCK_CONFLICT` 与建议，不静默改计划。

## 3:45–4:30 报价 / 排期 / 校验

- 报价页：刊例→折扣→制作→4A（直客为 0）→赠媒；逐行分摊校验通过。
- 排期：夜间 23:00–05:00、公交 20 辆/晚、地铁 10 口/晚、2 个雨备夜；批次 units == 计划 units。
- 监测：上刊照片、5 工作日监测、下刊 5 工作日、误一补二。
- 校验页：预算/库存/档期/配比/分摊/假设书 H1–H7；已知局限主动摊开（曝光是估算、折扣门槛待确认、地铁等级映射为假设）。

## 4:30–5:00 客户模式 + 静态导出

- 切“客户提案”：封面→假设书→策略→地图→组合→排期→报价→承诺→局限。
- 点“导出单文件”：下载 HTML；`file://` 打开，断网可切预算档；说明给客户的离线交付。
- 收尾：“从几天到一分钟；每个数字可追溯；评委现在可以改任意输入。”

## Q&A（现场高频）

**Q1：为什么不用竞品迪士尼站？**
A：家庭客群重叠但意图冲突；不买竞品门口。系统在 `why_not` 里明确列出。

**Q2：折扣 68% 怎么来的？**
A：按全单刊例总额落档，88/83/78/73/68%；门槛是赛前培训/PRD 口径，配置在一处，待赞助方确认。报价逐行加总可复算。

**Q3：库存是真的吗？**
A：红豆 API 2027 月度快照，跨月取最小可售；页面显示校验时间戳和档期。静态台账 free=2517 已过时，不用。

**Q4：Reach 82% 可信吗？**
A：是模型估算，不是实测；目标人群 250 万是策划假设；用饱和曲线封顶 82%，不把公交/地铁到达率相加；只做方案间相对比较，不承诺到园人数。

**Q5：为什么地铁只买 5 个口？**
A：地铁单价是公交的 5 倍左右；5 个枢纽口吃掉约 38% 预算，换来家庭出发拦截；公交 39 辆铺广度。按花费约 62/38、按点位数量约 89/11，是主动取舍。

**Q6：AI 在哪里？是不是套壳？**
A：AI 负责 brief 理解、策略检索、解释生成；预算/库存/报价/排期全部由 CP-SAT + 确定性规则完成。LLM 不产出数字，validator 独立校验；无 Key 自动离线，页面显示真实模式。

**Q7：换行业/换预算会崩吗？**
A：同一引擎；场馆/预算/媒体/档期都是参数。矩阵测试覆盖 3 场馆 × 3 预算 × 3 媒体组合；任意 100–500 万连续调参。

**Q8：现场断网怎么办？**
A：核心数据/地图/图表全部本地；生产模式无外部请求；静态单文件可断网打开。红豆刷新是构建期脚本，不在演示链路。

**Q9：为什么乐高不按 6km 圈选？**
A：乐高在金山枫泾、无地铁直达，硬套 6km 会选不到有效家庭客源；用 6/20/50km 圈层 + 家庭客源枢纽 + POI 浓度，模型说明书有公式。

**Q10：被占档期怎么办？**
A：按“同站其他口 → 相邻枢纽 → 同区县”替换并说明理由；库存与预算约束绝不放松；锁定冲突返回建议。
