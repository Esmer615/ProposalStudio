## 0. 一句话

给户外媒体公司做 **"输入 行业+预算+媒体+档期 → 当场产出可交互 HTML 提案"的 AI 提案工作台**。
技术核心是 **"AI 做取舍、算术做校验"**：LLM 输出结构化判断（目标权重、选点偏好、理由、合规），
确定性优化器负责预算/库存/排期/覆盖——所以评委现场改数，10 秒内可复现。

## 1. 评分拆解与硬规则

| 维度 | 分值 | 及格线 | 高分线 |
|---|---|---|---|
| 业务价值 | 30 | 对准真实痛点 | 资料之外的新洞察；把生意问题翻译成媒体问题 |
| 完成度与可用性 | 25 | 现场能跑、链路完整、HTML 可交互 | 企业能直接用；换行业/换预算不崩 |
| AI 应用质量 | 20 | AI 承担核心环节 | 工作流合理、决策有依据；不是套壳聊天 |
| 行业专业度 | 15 | 空车数/等级/刊例/监测/误一补二 | 让企业方说"我们没想到" |
| 演示表达 | 10 | 讲得清 | 取舍逻辑有说服力 |

**硬规则：**
- 链路缺环 → 不参与评奖
- 预录视频 / 截图轮播 / 固定脚本假演示 → 完成度 0 分
- 非脱敏数据（真实客户名、真实成交价）→ 每处扣 10 分
- **无《campaign 假设书》或方案与假设书对不上 → 业务价值封顶 18/30**

## 3. 方案路线对比

| 路线 | 做法 | 得分上限 | 最大风险 | 适合 |
|---|---|---|---|---|
| **A. 提案引擎 + HTML 工作台** | 表单 → AI 出假设书与权重 → 确定性优化器 → 可交互 HTML | 90+ | 优化器做不好会变"套壳表单" | 想拿名次 |
| B. Agent 工作流为主 | 多智能体 + 工具调用两个系统 → 输出 HTML | 85 | 现场不稳、输出不可控 | 赌 AI 分 |
| C. 单场景精品方案 | 1 行业 + 1 预算，极致方案 + 预算滑杆 | 70 | 换行业就崩，复用性丢分 | 只求完成 |
| **D. A 为主体 + B 做过程展示** | A 保稳；B 的阶段"过程回放面板"展示 AI 检索/圈选/校验，不做主链路 | **90–95** | 工时紧 | 2 天赛制 |

**推荐：D。**

理由：
1. 主链路确定性 → 现场改预算不翻车（25 分完成度）
2. AI 以结构化决策 + 过程可视化出现 → 不是套壳（20 分）
3. 单一优化器天然支持 100/200/500 连续调参 → 复用性满分（赛题最看重）

## 4. 推荐方案架构

```
输入层   行业 / 预算 / 媒体 / 档期
   ↓
AI 策略层（LLM，结构化输出 JSON）
   · 品牌与 campaign 调研 → 《campaign 假设书》七要素
   · 生意目标 → 媒体目标翻译
   · 行业权重：人群画像、区域偏好、时段偏好、等级偏好
   · 合规红线（金融/医疗/保健）
   ↓
数据层
   · 红豆库存快照（公交 552 / 地铁 861，按 2027 档期）
   · 可视化平台覆盖分析导出（地标 + 半径 → 周边线路）
   · 刊例价表（区间取中值 + 折扣）
   ↓
决策引擎（确定性，可复现）
   · 门店/地标圈选 → 候选媒体集合
   · 库存过滤（空车数 ≥ 需求，档期可售）
   · 集合覆盖去重 → 覆盖人次/成本效率排序
   · 预算约束下的组合优化（贪心 + 局部搜索）
   · 施工产能约束（单晚上限、分批、雨天缓冲）
   · 冲突自动替换（等级 + 地理相似度）
   ↓
输出层
   · 可交互 HTML（预算滑杆、地图、清单、排期、报价、SLA）
   · 一页纸《campaign 假设书》
   · 每晚施工计划 / MR 台账
   · 反事实解释（为什么没选 X / 砍预算先砍谁）
```

**复用机制（关键）：** 不写三套方案，只用**一个优化器 + 优先级序列**。
100/200/500 只是"截断点"，砍预算按边际覆盖效率从低到高依次砍。现场演示即"拖动滑杆 → 重算"。

## 5. 6 个"评委没想到"的加分点

1. **档期与夜间施工产能模型**：单晚上刊上限、雨天顺延、误一补二缓冲 → 排期能落地
2. **库存冲突自动降级替换**：目标线路被占 → 自动换线并说明理由（红豆"空车数"直接变现）
3. **覆盖去重**：用覆盖分析做集合覆盖，不简单相加人次，按"每人次成本"排序
4. **反事实解释**："为什么没选 X""砍 50 万先砍哪 3 条"——现场高频提问
5. **合规校验**：金融不得承诺收益、医疗不得疗效承诺、保健不得功效
6. **假设书回链**：方案每模块标注"对应假设书第 N 条"，直接咬住评分规则
