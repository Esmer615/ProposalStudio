## 1. 请求 `PlanRequest`

```json
{
  "industry": "乐园",
  "venue": "lego_shanghai",
  "budget_wan": 500,
  "media": ["bus", "metro"],
  "start_date": "2027-07-01",
  "weeks": 8,
  "customer_type": "direct",
  "locks": { "include": [], "exclude": [] },
  "brief_text": null
}
```

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `industry` | string | 是 | 固定 `"乐园"`；未来可扩展 |
| `venue` | string | 是 | `lego_shanghai` / `disney_shanghai` / `haichang_shanghai` |
| `budget_wan` | number | 是 | 100–500，连续；步长建议 10/25 |
| `media` | string[] | 是 | 子集 `["bus","metro"]`，至少 1 项 |
| `start_date` | string | 是 | `YYYY-MM-DD`，2027 年内；必须落在已抓取月份内 |
| `weeks` | int | 是 | 2/4/6/8/12；默认 8 |
| `customer_type` | string | 是 | `direct`（直客，无 4A 费）/ `4a`（4A，15% 服务费） |
| `locks.include` | string[] | 否 | 资源 ID，如 `bus:17:大三侧`、`metro:人民广场:14号口`；锁定必须在库存内 |
| `locks.exclude` | string[] | 否 | 同上；从候选移除 |
| `brief_text` | string? | 否 | 自然语言 brief；仅用于策略解析，不进入算术链路 |

**规范化**：后端会把 `media` 排序、去重；`start_date` + `weeks` 转为 `end_date`；`months` = 覆盖的月份数（按自然月计费，向上取整）；响应 `inputs` 回显规范化结果。

## 2. 响应 `PlanResponse`

### 2.1 `meta`

| 字段 | 类型 | 说明 |
|---|---|---|
| `version` | string | 引擎版本 |
| `generated_at` | string | ISO8601 +08:00 |
| `request_id` | string | 请求哈希/ID |
| `solve_ms` | int | 求解耗时 |
| `total_ms` | int | 全链路耗时 |
| `data_version` | string | 数据版本（manifest SHA256 前 12 位） |
| `inventory_ts` | string | 红豆快照抓取时间 |
| `inventory_periods` | string[] | 快照覆盖月份 |
| `solver` | string | `CP-SAT` / `HiGHS` / `Greedy` |
| `fallback_chain` | string[] | 降级链；空数组表示主路径 |
| `status` | string | `OPTIMAL` / `FEASIBLE` / `INFEASIBLE` |
| `cache_hit` | bool | 是否命中缓存 |

### 2.2 `inputs`

规范化请求 + `end_date`、`months`、`venue_name`、`customer_type_label`。

### 2.3 `hypothesis` — Campaign 假设书七要素

```json
{
  "fields": [
    { "id": "H1", "label": "客户与品牌", "value": "..." },
    { "id": "H2", "label": "生意目标", "value": "..." },
    { "id": "H3", "label": "Campaign 目标", "value": "..." },
    { "id": "H4", "label": "目标人群", "value": "..." },
    { "id": "H5", "label": "时间与预算", "value": "..." },
    { "id": "H6", "label": "媒体范围", "value": "..." },
    { "id": "H7", "label": "成功衡量", "value": "..." }
  ],
  "one_liner": "一句话策略",
  "assumptions": ["策划假设1", "策划假设2"]
}
```
- `H1..H7` 必须非空；方案每个模块回链 `hypothesis_refs`。
- 缺失或与方案矛盾 → validator `blocker`，不生成客户提案。

### 2.4 `strategy`

`one_liner`、`audience{primary, secondary, persona, activity_area}`、`transport{self_drive_share, rail_share, metro_access, note}`、`media_roles[{media, role, share_target}]`、`mix_rationale`、`compliance{forbidden[], notes[]}`、`creative[]`、`avoid[]`。

### 2.5 `venue`

`id`、`name`、`district`、`coords{lng,lat}`、`confidence`（`approx`/`low`）、`rings_km[]`、`access{...}`、`target_population`、`reach_k`、`source`。

### 2.6 `plan`

```json
{
  "bus": [PlanItem],
  "metro": [PlanItem],
  "summary": {
    "bus_units": 30, "metro_units": 6, "bus_lines": 8, "metro_stations": 6,
    "media_mix": { "bus_pct": 0.482, "metro_pct": 0.518 },
    "unit_mix": { "bus_pct": 0.829, "metro_pct": 0.171 },
    "level_mix": { "S": 11, "A++": 15, "A+": 9 },
    "district_mix": { "浦东新区": 5, "黄浦区": 5, ... },
    "gross_wan": 618.0, "net_wan": 451.14, "total_paid_wan": 473.07,
    "budget_utilization": 0.946, "poi_hits": 37, "free_verified": 35
  }
}
```

- `media_mix` 按**折后媒体费**计算；`unit_mix` 按 units 计算（乐高样例：花费约 48/52，点位数量约 83/17）。二者都展示，避免“按数量看起来地铁很少、按花费却接近一半”的误解。

**PlanItem**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `bus:{line}:{media_type}` 或 `metro:{station}:{exit}` |
| `kind` | string | `bus` / `metro` |
| `name` | string | 展示名 |
| `line` | string? | 公交线路名 |
| `company` | string? | 公交运营公司 |
| `station` | string? | 地铁站名 |
| `exit` | string? | 地铁出入口 |
| `district` | string | 区县/区域 |
| `level` | string | S / A++ / A+ / AA / unknown |
| `media_type` | string | 大三侧 / 车身三侧 / 地铁出入口 |
| `units` | int | 公交车辆数 / 地铁口数 |
| `free_count` | int | 红豆 min_free（跨月最小可售） |
| `unit_price_wan` | number | 刊例单价（万/月） |
| `months` | int | 计费月数 |
| `gross_wan` | number | 刊例小计 = 单价×units×months |
| `discount` | number | 全单折扣（0–1） |
| `net_wan` | number | 折后媒体费 |
| `production_wan` | number | 制作费 |
| `agency_fee_wan` | number | 4A 分摊 |
| `total_wan` | number | 行分摊总价 |
| `gift` | bool | 是否赠媒（不计付费 KPI） |
| `score` | number | 综合评分 |
| `score_breakdown` | object | `exposure, audience_fit, poi, zone, corridor, cost_efficiency` |
| `reasons` | string[] | 选点理由（可逐条质询） |
| `evidence` | object[] | `{type, text, source}`，如库存/POI/换乘 |
| `alternatives` | object[] | `{id, name, reason}` 替代项 |
| `geo` | object | `{type:"point"|"line"|"schematic", coords?, path?, district?, confidence}` |
| `hypothesis_refs` | string[] | H1–H7 回链 |
| `locked` | bool | 用户锁定 |
| `status` | string | `paid` / `gift` / `replaced` |

**地铁 level 假设**：红豆 `lineLevel` 2=A++、3=A+（代码集中配置，页面与说明书标注“假设”）；空/未知不入方案。

### 2.7 `effects`

```json
{
  "impressions": 55147680,
  "grp": 2205.9,
  "reach": 0.8196,
  "reach_pct": "82.0%",
  "frequency": 26.91,
  "cpm_yuan": 81.8,
  "target_population": 2500000,
  "parameters": {
    "reach_cap": 0.82, "k": 260, "k_eff": 286,
    "view_rate_bus": 0.60, "view_rate_metro": 0.50, "days": 56
  },
  "by_media": [
    { "media": "bus", "impressions": 43303680, "share": 0.785, "cpm_yuan": 50.2 },
    { "media": "metro", "impressions": 11844000, "share": 0.215, "cpm_yuan": 197.2 }
  ],
  "by_line": [ { "id": "bus:17:大三侧", "impressions": 7022080 } ],
  "formula": "Reach = reach_cap × (1 − exp(−GRP/k_eff)); Frequency = (GRP/100)/Reach; CPM = 折后媒体费/曝光×1000",
  "disclaimer": "曝光估算，不是到园人数/销量/财务 ROI；目标人群为策划假设。"

```
- 公交+地铁合并用单一饱和曲线，`by_media` 只做归因，**不可相加成到达率**。

### 2.8 `elasticity`

```json
{
  "unit": "万元",
  "points": [
    {
      "budget_wan": 100, "impressions": 8000000, "reach": 0.52,
      "frequency": 6.2, "cpm_yuan": 68.0,
      "marginal_impressions_per_wan": 140000,
      "delta_reach": 0.0, "is_current": false
    }
  ],
  "knee_budget_wan": 350,
  "note": "同一引擎按预算重解；拐点=边际每万元曝光开始明显下降。"

```
- 默认 9 点：100/150/200/250/300/350/400/450/500。
- `is_current=true` 仅一项；当前预算不在九点时前端自行标记区间。

**2.11.1 真实公交线路几何（2026-11-22 新增，可选字段）**

- Agent 在引擎后调用 `xinyun-bigdata` AI线路，把真实几何注入 `coverage.map_layers`：
  - `bus_routes[]`：`{line, lineName, lineId, items[], geometry:{type:"line", path:[[lng,lat],...], points, simplified}, bbox, source, data_month:"202305", confidence:"approx", fetched_at}`
  - `bus_routes_meta`：`{source, data_month, status, reason, fetched_at, note}`
  - `bus[].route_ref` / `bus[].route_status`（`ready|missing|unavailable`）
- `plan.bus[].route_ref` / `route_status`：表格/抽屉联动。
- 运行包装层另有 `run.data.routes` 摘要与 `GET /api/proposals/{run_id}/routes.geojson`；字段与降级规则见 `docs/route-geometry-api.md`。
- 边界：2023-05 轨迹快照，仅用于可视化；**不参与报价/库存/Reach/评分**，缺失线路按区县示意。

## 3. 错误对象

```json
{
  "error": {
    "code": "LOCK_CONFLICT",
    "message": "锁定的地铁口在目标档期不可售",
    "field": "locks.include",
    "suggestions": ["取消锁定", "改选相邻出口", "提高预算"],
    "recoverable": true
  }
}
```

| HTTP | code | 场景 |
|---|---|---|
| 422 | `VALIDATION_ERROR` | 输入不合法/场馆/日期不支持 |
| 409 | `INFEASIBLE` | 约束下无可行解（预算/配比/库存） |
| 409 | `LOCK_CONFLICT` | 锁定项无库存/被排除/冲突 |
| 422 | `DATA_UNAVAILABLE` | 目标月份未抓取 |
| 500 | `INTERNAL` | 未预期异常（保留 request_id） |

## 4. HTTP 头与端点

- `GET /api/health` → `{status, python, solver, data_version, inventory_periods}`
- `GET /api/meta` → `{venues, media, dates, budget_range, rate_card, discount_tiers, default_request, manifest}`
- `POST /api/plan` → `PlanResponse`
- `POST /api/plans/batch` → `{plans: PlanResponse[]}`（100/200/500）
- `POST /api/elasticity` → `{points, knee_budget_wan, note}`
- `POST /api/export` → `text/html`（单文件提案）
- `GET /api/data/manifest` → manifest
- 响应头：`X-Data-Version`、`X-Cache`、`X-Solve-Ms`；CORS 仅本地。

### 4.1 静态导出载荷（已移除，保留作历史记录）

`POST /api/export` 返回 `text/html`，页面内 `__PLAN_PAYLOAD__` 占位符被替换为：

```json
{
  "mode": "static-export",
  "generated_at": "2026-11-21T20:30:00+08:00",
  "default_budget_wan": 500,
  "tiers": [100, 150, 200, 250, 300, 350, 400, 450, 500],
  "plans": { "100": PlanResponse, "150": PlanResponse, "...": "..." },
  "data_version": "abc123",
  "inventory_ts": "2026-11-21T20:00:00+08:00"
}
```
- 某一档不可行时，`plans["X"]` 为 `{error, inputs}`；前端显示“该档不可行/建议”。
- 前端静态模式按 `plans[String(budget)]` 切换；若无对应档，显示最近可行档并注明。
- 导出文件不得包含凭证/token/外部 CDN；`scripts/verify_export.py` 扫描。

## 6. 数据版本与可复现

- `data_version` = SHA256(manifest + config + venue profile) 前 12 位；缓存键包含它。
- 同输入重复调用，除 `meta.generated_at/request_id/solve_ms/total_ms/cache_hit` 外必须完全一致。
- 库存校验时间戳、档期、数据版本必须出现在响应与页面。
