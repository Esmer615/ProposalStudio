一、这家企业
上海新云传媒，1997 年成立，上海头部户外媒体运营商，三类媒体资源：

近 5000 台公交车身（上海保有量首位）
独家运营上海全线近 1000 个地铁口点位
近 10000 平米城市地标级商圈媒体
客户来自快消、金融、汽车、美妆、通讯等行业。

二、业务挑战
客户要投放，当天就要看到方案。现实里销售要人工查哪些线路有空位、什么级别、什么价格、怎么组合，再做一份完整提案——一套流程要好几天，响应慢，单子就被竞对拿走。价格与组合怎么定，今天靠销售翻刊例、凭个人经验算折扣。

三、赛题：给定行业与预算，产出完整投放方案
你是一家户外媒体公司的提案团队。客户来自指定行业、预算已定，要求基于公司真实的媒体库存与大数据平台，当天产出一份可直接向客户演示的投放方案。

输入（四项）：
行业（五选一）：银行保险 / 食品饮料 / 保健品 / 私立医院 / 乐园（主题公园）。在选定行业内，自选一家在上海有线下门店的头部企业作为目标客户——品牌由你调研确定，不限定具体公司；
预算（三选一）：100 万 / 200 万 / 500 万；
投放媒体：公交车身、地铁出入口（可单选或组合）；
投放档期：2027 年内（以红豆系统实际可售档期为准）。
数据底座（比赛专用账号请从上方领取表领取）：
红豆广告媒体管理系统（flairmedia.com.cn:881）：媒体管理 → 媒体库，含公交媒体库 552 条、地铁媒体库 861 条真实线路/点位库存。「空车数」即当前可售数量；合同车 = 在刊或已签合同，预定车 = 销售暂占档期；点击数字可查看占用明细。库存按日期查询，提案排期须与可售档期核对。系统内数据可导出。
新云大数据可视化平台（flairmedia.com.cn:38880）：区域人流查询（媒体查询，注意数据月份请选择 2023 年）、媒体覆盖分析（输入地标/坐标与半径，反查周边公交地铁媒体）、AI 线路（画线、保存并生成可在线预览的 HTML 链接）。
产出要求：
交付形式为 HTML：一份完整、可交互的投放方案（品牌理解、媒介组合、线路/点位清单、排期与报价），路演现场可直接打开演示；
复用性要求：同一套方案在 100–500 万区间可通过增减媒介灵活调整，建设在面对不同客户时，重新制作提案所消耗的时间；
评分看重「需求与媒介的结合」：品牌调研与 campaign 理解 → 门店/地标圈选 → 覆盖分析找线路 → 红豆核对可售 → 组合成案。链路顺序不限，但必须逻辑自洽。
四、赛制要求
分工：每组 4 人，围绕同一赛题自行分工（品牌调研与策略 / 数据与系统使用 / AI 工作流与开发 / 演示答辩）。

形态：Web 应用、命令行工具、Agent 工作流、数据分析+自动化组合均可，路演现场可运行即可。

数据：只能使用赛题发放的系统账号（红豆 + 可视化平台）与资料包中的脱敏材料，不得接入任何其他真实企业系统；两个系统均为比赛开设专用账号，客户与业务数据已脱敏。

演示：评委现场指定行业/预算组合或要求调整预算，作品须当场产出或调整方案并讲解；预录视频、截图轮播不计。

五、没有标准答案
公司列出了痛点，但没有标准答案。资料包内容是参考，不是照单施工的图纸——可以全部用、只用一部分，甚至提出资料之外的问题。能提出公司没想到的解法，本身就是高分项。
