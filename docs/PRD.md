## 1. 背景与问题

### 1.1 现状

上海新云传媒是上海头部户外媒体运营商，拥有近 5000 台公交车身、近 1000 个地铁口点位、近 10000 平米商圈媒体。客户来自快消、金融、汽车、美妆、通讯等行业。

销售做一份投放提案的现状：

1. **人工查库存**：翻红豆系统，查哪些线路/点位有空位、什么级别、什么价格。
2. **凭经验定组合**：什么媒介配比、什么折扣，靠销售翻刊例、凭个人经验拍。
3. **手工拼提案**：再做一份 PPT/文档，排期、报价、方案全手工。

**结果：一套流程要好几天。客户当天要方案，单子就被竞对拿走。**

### 1.2 核心痛点（一句话）

> **「查库存—定组合—算报价—出方案」的整条链路，没有自动化；每步都依赖销售个人经验，既慢又不可复制。**

### 1.3 我们解决的是哪一环

不是做一个"会写漂亮 PPT 的 AI"，而是做一个**确定性工具**：把"好几天"压到"改一个滑杆"，而且每一步都可溯源、可复算。

## 2. 产品定位

### 2.1 一句话定位

> **给户外媒体公司的销售，造一个「当天出提案」的 AI 工作台。**

### 2.2 定位的三个边界（重要，决定我们做什么不做什么）

| 边界 | 决定 |
|---|---|
| 这是**曝光覆盖**工具，不是**转化归因**工具 | 度量是"每万元买到多少目标人群曝光"，不假装算出"投了多少广告 → 来了多少人" |
| 这是**确定性决策**工具，不是**生成式文案**工具 | 报价、库存、组合锁死在可复算的规则里；AI 只用于"理解客户"和"解释选点理由" |
| 这是**销售桌面工具**，不是**运营后台** | 单文件离线可开，销售自己电脑双击就能用，不需要服务器、不需要 API Key |

### 2.3 与赛题要求的对应

| 赛题要求 | 本产品实现 |
|---|---|
| 基于红豆真实可售库存 | ✅ 库存只取 `available>0` 的记录，采购量不超过空车数 |
| 大数据可视化平台 | 🔶 POI 人群层 + 圈层人口（当前为自建估算，接口预留可视化平台数据接入） |
| 给定行业+预算产出可交互 HTML | ✅ 输入行业/品牌/预算/媒介/档期 → 单文件 HTML 提案 |
| 100–500 万预算可伸缩 | ✅ 预算滑杆实时改算 + 九档弹性对比 |
| 评委现场改输入当场出结果 | ✅ 全量重算 < 200ms，离线可跑 |

## 3. 目标用户与使用场景

### 3.1 目标用户

| 用户 | 角色 | 核心诉求 |
|---|---|---|
| 新云传媒销售 | 主用户 | 客户要方案当天能出；客户砍预算能快速改；报价有依据 |
| 提案策划（资深） | 主用户 | 把个人经验沉淀成可复用的策略，而不是每次从头想 |
| 客户（广告主） | 间接用户 | 看得懂"为什么这么买、每笔钱买到了什么" |

### 3.2 关键使用场景（按优先级）

**P0 场景 A：当天出首版提案**
销售拿到 brief（行业+预算），输入四项，30 秒内得到一份可给客户看的 HTML 提案。

**P0 场景 B：客户现场砍预算**
客户说"100 万做不做得了"，销售拖滑杆，当场告诉客户"少买的是什么、代价是什么"。

**P0 场景 C：评委/客户现场换行业**
"如果换成私立医院呢"，下拉切换行业，场地、人群、媒介配比全部跟着换，200ms 出结果。

**P1 场景 D：经验沉淀**
资深策划把历史方案（组合+效果）回填，新人下次做同类客户时，系统自动检索相似案例作参考。

**P1 场景 E：跨品牌复用**
同一套引擎，换目标客户（乐高/迪士尼/研学景点），策略自动按该品牌的交通结构、人群结构重算。

## 4. 功能需求

### 4.0 输入（控制条）

| 输入 | 类型 | 说明 |
|---|---|---|
| 行业 | 下拉（5 选 1） | 银行保险 / 食品饮料 / 保健品 / 私立医院 / 乐园 |
| 目标客户/场地 | 文本/下拉 | 随行业联动，如乐园下的乐高/迪士尼/海昌 |
| 预算 | 滑杆 100–500 万 | 步长 50 万，实时重算 |
| 投放媒介 | 多选 | 公交车身 / 地铁出入口 |
| 投放档期 | 下拉 | 2/4/8/12 周 |

### 4.1 品牌理解（✅）

- 五个行业各有独立档案：人群、场景、核心判断、创意主打、衡量口径、**必须避开的坑**、档期建议。
- 提案主线（一句话策略）随行业/场地自动生成。
- 验收标准：换行业时，人群定义与"必须避开"必须随之改变，不能是通用套话。

### 4.2 圈选与覆盖分析（✅）

- **场地区**：按行业定半径（医院 5km、快消门店 2.5km、乐园 6km）。
- **客源圈**：行业专属客源加权 1.35 倍（如金融的古北/联洋、医院的碧云）。
- **枢纽圈**、**廊道节点**：支持换城市（同一城市圈层）。
- 地图可视化：圈层 + 已选点位 + 场地标记。
- 验收标准：换行业时场地必须跟着换（银行→网点、医院→医院），否则是"拿乐园的场地算银行的钱"。

### 4.3 POI 人群层（✅ 本次核心）

**这是本产品区别于"按价格排序选点位"的关键。**

- 建立 POI 库：学校（公立/私立）、少年宫、科技馆/博物馆/天文馆、儿童医院、亲子社区。
- 每个媒体点位计算**周边 300–900 米内 <20 岁人群浓度**（分类型半径，距离衰减）。
- 每个选点理由可逐条质询："周边 N 个 <20 岁人群聚集点（科技馆/博物馆等），浓度 X%"。
- 验收标准：浓度高的点位优先被选中；预算变化时，选点类型自然地从"少而精"向"广而泛"溢出。

### 4.4 媒介组合（✅）

- **预算切盘子**：按行业基准把预算切成公交/地铁两个盘子，盘子内按性价比贪心。
- **红豆可售核对**：只允许 `available>0`，采购量不超过空车数。
- **边际递减**：同一站点/线路重复投放收益衰减（0.72^n）。
- 每条选点带理由与出处。
- 验收标准：换预算后组合单调变化（加钱不推翻之前的选点，是"扩充"不是"重排"）。

### 4.5 报价（✅）

- 折扣按**全单刊例总额落档**（88/83/78/73/68%），全单统一折扣。
- 满额赠送：折后 5% 等值点位。
- 4A 代理服务费 15%（直客不适用）。
- 验收标准：单条点位分摊加起来 == 总报价（不能出现"分摊 ≠ 报价"）。

### 4.6 排期（✅）

- 高分点位统一上刊，长尾延后 1–2 周，降低一次性制作与上刊压力。
- 甘特图可视化。

### 4.7 预算弹性（✅ 本次核心）

- **双轴折线图**：X=预算 100→500 万；蓝柱=累计 <20 岁曝光（左轴）；红线=**边际每万元曝光**（右轴）。
- 九档预算对比表（公交车数 / 地铁点位 / 折后 / 折扣 / <20岁曝光 / 累计每万 / 边际每万）。
- 验收标准：红线整体递减；能一眼看出"再加钱不划算"的拐点。

### 4.8 投产比（✅ 本次核心）

- 定义：`投产比 = 目标人群曝光（人次） / 预算（万元）`，即"每万元买到多少 <20 岁人群曝光"。
- 明确这是**曝光产出比**，不是财务 ROI（见 4.10 自检）。

### 4.9 自检与局限（✅）

- 四+项自动校验：红豆可售校验、预算贴合、媒介配比、档期对齐。
- 显式列出已知局限：触达是估算、折扣是区间口径、POI 坐标是近似值等。
- 验收标准：**宁可标"未确认"，不给一个看起来漂亮的假数字。**

### 4.10 后续规划（P1，未实现）

- [ ] 案例库：历史方案（组合+效果）→ 检索式先验，辅助新方案生成（case-based reasoning）。
- [ ] 可视化平台「AI 线路」画线结果接入，替换自建廊道/POI 距离。
- [ ] 报价页「误一补二 / 监测条款」承诺块（依资料包 03 合同样本）。
- [ ] 五行业样板 HTML 批量生成。

## 6. 核心算法逻辑（评分模型）

> 这一节是给评委看的"机制说明"，也是团队内部对齐的口径。

每个候选媒体点位的综合分：

```
score = 0.34·地理相关度
      + 0.13·圈层角色权重（行业档案决定）
      + 0.10·媒体等级（S/A/B/C）
      + 0.28·廊道权重（直达 1.0 / 换乘 0.55）
      + 0.15·千人成本（反向归一）
      + audienceW·<20岁人群浓度（本次新增，乐园行业 = 0.5）
```

**缺客流数据时**：千人成本维度权重自动让给地理与 POI 浓度，不拿假数据排序。

**预算切分**：公交/地铁两个盘子按行业基准配比（如乐园 68/32），盘内按 `score×边际衰减 / 净成本` 贪心，余额流向另一盘子。

**报价收敛**：折扣按全单落档，"预算→能买多少刊例"是不动点问题，4 轮迭代收敛，保证单条分摊 == 总报价。

## 10. 风险与依赖

| 风险 | 影响 | 应对 |
|---|---|---|
| 红豆真实库存未接入 | 方案基于演示数据，说服力打折 | 用 `import_export.mjs` 接导出件，一条命令切换 |
| POI 坐标是近似值 | 评委追问"这个坐标哪来的" | 标注 `confidence=approx`，答辩主动说明，接入可视化平台后替换 |
| 触达是估算非实测 | 被质疑"数字不可信" | 并集公式 + 显式口径，只做方案间相对比较 |
| 学校投放合规 | 措辞不当变硬伤 | 口径统一为"学校周边 300–500 米"，不投校内 |
| 评委现场改不常见组合 | 组合跑不出合理结果 | 引擎对任意行业/预算/媒介组合都返回结果，无 NaN（自检覆盖） |
