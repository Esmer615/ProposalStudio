## 3. 数据使用说明

| 数据 | 来源 | 用途 |
|---|---|---|
| 公交/地铁可售库存、空车数、等级、出入口 | 红豆广告媒体管理系统（比赛专用账号，只读 API，2027 月度快照） | 唯一库存事实来源；组合/报价/排期 |
| 刊例价、制作费 | 资料包 07-媒体刊例价（区间中值，脱敏口径） | 报价底座 |
| 合同/SLA | 资料包 03 合同、02 上下刊流程卡点、06 4A brief | 误一补二、监测、夜间施工、缓冲 |
| 场地/POI/区县/站点坐标 | 公开信息整理 + 近似坐标；构建期缓存 | 圈层/地图/评分，标注 `approx/low` |
| 客流/曝光 | 等级经验值 + 公开信息，模型估算 | Reach/Frequency/CPM，明确标注估算 |
| 最终数据资产 | manifest `f786985a2947` | 6,972 条库存记录 / 1,256 条候选 / 103 个 POI / 275 个地铁站坐标 / 16 区 GeoJSON |

- **合规**：只使用赛题发放的账号与脱敏资料包；不接入其他真实企业系统；不展示真实客户名/真实成交价；不投校内；页面显示库存校验时间戳与档期。
- **可追溯**：每个数字有 `data_version`、来源、公式、假设或“未确认”标记；宁可标“未确认”，不给假数字。

## 4. 已知局限

1. 曝光/Reach/Frequency/CPM 为估算，不是实测触达；目标人群为策划假设。
2. 折扣档位门槛 88/83/78/73/68% 来自赛前培训/PRD 口径，待赞助方确认。
3. 地铁 `lineLevel` 2=A++ / 3=A+ 为假设；红豆未给精确等级语义。
4. POI/公交几何为公开近似或区县示意；不用于测量级结论；POI 共 103 个（目标 112+，已知差 9 个）。
5. 库存为查询时点快照，档期占用会变化；现场演示前需刷新/核对。
6. 不做转化归因：本工具衡量“每万元买到多少目标人群曝光”，不假装算出到园人数或销量。
7. 九档弹性为同一优化器的确定性预算扩展估值（greedy），主方案为 CP-SAT；两者共享库存/配比/预算规则，数值可能不同。
7. 历史案例库/可视化平台“AI 线路”实时接入为后续迭代；当前用构建期缓存与离线数据。
