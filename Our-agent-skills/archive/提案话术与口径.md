# Skill · 提案话术与口径

> 版本 v1.0 ｜ 归属：新云媒介提案台
> 定位：**前两个 skill 教你怎么算和怎么想，这个教你怎么说。**

---

## 0. 为什么需要一个"说话"的 skill

同一份计算结果，说法不同，可信度天差地别：

> ❌「本方案预计触达 287 万人次目标人群，ROI 显著提升」
> ✅「本方案在 POI 估算口径下触达目标人群 287 万人次；实际到园转化无法归因，所以我们不承诺人数」

前者像 PPT，后者像人话。评委和客户都会更信后者。

**这个 skill 的唯一目标：让你的每一句话都能被追问而不崩。**

---

## 1. 四条铁律

### 铁律 1：数字必须带口径

任何曝光/触达数字，后面必须跟一个来源标签：

| 数据来源 | 必须怎么说 |
|---|---|
| `platform` | 「平台区域人流实测（2023 年 10 月口径）」 |
| `poi_estimate` | 「POI 估算口径，非平台实测」 |
| `mixed` | 「部分点位用平台数据，部分用 POI 估算」 |

**没有标签的数字 = 编的。**

### 铁律 2：曝光 ≠ 到园

| ❌ | ✅ |
|---|---|
| 预计带来 X 人到园 | 预计触达 X 万人次，实际到园无法归因 |
| ROI 达到 X | 每万元买到 X 人次目标曝光 |
| 转化率 X% | 这个数字我们没有数据支撑，不给 |

户外广告没有点击、没有归因链路。**说能算到园转化的，都是在赌。**

### 铁律 3：钱没花完必须说

见 [计算 skill 规矩 1](./投放方案计算与比选.md)。

### 铁律 4：不投校内

统一措辞：**"学校周边 300–500 米的地铁/公交点位"**。

## 2. 按场景的话术模板

### 2.1 开场（30 秒内建立可信度）

> 「这单我们给两个方案：一个打精准，一个打覆盖。我先说结论，再说为什么——**所有数字都标了口径，你们随时可以质疑。**」

**为什么这样开场**：主动暴露"我准备被质疑"，比全程自信更有说服力。

### 2.2 报方案（结构化三句）

```
第一句：方案是什么（策略 + 关键数字）
第二句：为什么这么买（库存约束 / 人群判断）
第三句：代价是什么（这个方案牺牲了什么）
```

示例：
> 「**广度方案**：84 个点位，200 万花掉 197.9 万，触达目标人群 636 万人次（POI 估算口径）。
> 这么买是因为 200 万如果只投科技馆，16 个点位就买满了，钱花不出去。
> 代价是浓度摊薄——目标人群占比从精准方案的 73% 掉到 42%。」

**第三句最重要**：主动说代价，比藏着掖着强十倍。

### 2.3 被问"你们这个数据哪来的"

> 「分三层：
> 库存和刊例——红豆系统实时导出，空车数就是可售量；
> 人流量——目前是 POI 推算，接入可视化平台区域人流后会换成实测；
> 折扣——按全单刊例总额落档，不是我们拍的。
> 哪一层你想细问，我都能指到原始数据。」

### 2.4 客户砍预算

> 「砍到 100 万，我们不用重做方案——拖一下滑杆，系统 200 毫秒重算。
> 但你要知道代价：从广度掉到精准，点位从 84 个掉到 16 个，覆盖从 636 万掉到 127 万。
> **精准方案每一分钱都更值，但只有 32 万花得出去。**」

**这就是"预算弹性"的真实用法——不是展示能力，是当场告诉他取舍。**

### 2.5 被问"为什么不用 AI 直接生成方案"

> 「报价和库存算错了是商业事故。评委现场改预算，我们要 200 毫秒出结果，而且**每次必须一样**——大模型做不到确定性复算。
> AI 我们用在两个地方：理解客户需求、解释选点理由。算钱的部分锁在规则里。」

### 2.6 被问"这个方案能落地吗"

> 「单文件 HTML，销售在自己电脑上双击就开。接红豆导出件一条命令。不需要服务器、不需要 API Key。」

## 3. 五个高频问题的标准答案

| 问题 | 一句话答案 |
|---|---|
| **目标人群怎么定义？** | 平台数据只到 <20 岁这一档，我们就用这个口径；需要更细年龄段得额外调研 |
| **为什么投学校周边？** | 不投校内。投学校周边 300–500 米的地铁/公交点位，合规且同人群 |
| **曝光会不会重复？** | 会。到达率用并集公式 1-Π(1-p) 去重，不直接相加 |
| **为什么 500 万能花完，100 万反而花不完？** | 反过来——100 万投精准点位买不满预算，500 万靠公立学校+大流量点位才铺得开。**预算越高越需要广度** |
| **换一家乐园（迪士尼）还成立吗？** | 成立，但策略会变。迪士尼有 11 号线直达，可以加廊道拦截；乐高没地铁，只能打家门口曝光。**同一个行业，交通结构不同就是两套打法** |

## 4. 危险措辞对照表

| 危险说法 | 为什么危险 | 改成 |
|---|---|---|
| "投在学校里" | 合规红线 | "学校周边 300–500 米" |
| "预计带来 X 人到园" | 无法归因 | "触达 X 万人次，到园不可归因" |
| "ROI 达到 X" | 户外无转化数据 | "每万元买到 X 人次目标曝光" |
| "触达 287 万人"（无口径） | 会被追问口径 | "触达 287 万人次（POI 估算口径）" |
| "这是最优方案" | 抹杀了权衡 | "这两个方案分别适合…" |
| "AI 生成的方案" | 暗示不可控 | "规则引擎计算 + AI 解释" |
| "全上海都能看到" | 夸大 | "覆盖 X 个圈层的 Y 万人次" |

## 5. 数字表述规范

| 场景 | 格式 | 示例 |
|---|---|---|
| 预算 | 万元 | "200 万" |
| 报价 | 万元，一位小数 | "197.9 万" |
| 曝光 | 万人次 | "636 万人次" |
| 效率 | 人次/万元 | "31,810 人次/万元" |
| 折扣 | 百分比整数 | "73%" |
| 占比 | 百分比整数 | "42%" |

**禁止**：说"约 300 万"这种模糊数（要么给准确值，要么说"约"并给区间）。

---

## 6. 三个"必须主动说"的局限

在方案讲完、还没被问之前，主动说这三条：

1. **触达是估算，不是实测**（除非已接平台数据）
2. **折扣是区间化口径**，真实折扣依合同类型浮动
3. **POI 坐标是公开信息推算的近似值**，接入平台后替换

> 「这三条是我们自己写的局限页，就在提案最后一屏。**先自己说出来，比被你们问出来强。**」
