---

## 0. 这个 skill 解决什么问题

计算模型能算任何策略，但**策略得你来设计**。同一个 200 万预算，投科技馆和投公立学校是两个完全不同的商业主张，模型不会告诉你哪个对——那是判断，不是计算。

你在这个 skill 里的工作是：**基于客户的实际约束，设计出值得跑的策略组合。**

---

## 1. 先问清三件事（不问清就别急着算）

### 1.1 这一单要的是「精准」还是「覆盖」？

| 客户说法 | 真实需求 | 该走的策略 |
|---|---|---|
| "我们要触达目标客户" | 精准 | `precision` / `balanced` |
| "我们要让全上海看到" | 覆盖 | `reach` |
| "预算就这么多，怎么花最值" | 效率 | 跑多个，比 efficiency |
| "老板要看曝光量" | 数字好看 | `reach`，但要提醒效率下降 |

### 1.2 预算和点位数是不是匹配？

**这是最容易翻车的地方。** 你们的目标人群聚集点是有限的：

| 类型 | 全上海数量 | 100 万能买空吗 |
|---|---|---|
| 科技馆/博物馆 | ~14 | 能 |
| 少年宫 | ~16 | 能 |
| 儿童医院 | ~9 | 能 |
| 私立学校 | ~32 | 差不多 |
| 公立学校 | ~900 | 远远不能 |
| 亲子社区 | ~120 | 不能 |

**所以预算一提高，就必须向下一档类型溢出**——这不是策略选择，是库存约束。你要在提案里把这个约束讲成"分档逻辑"，而不是"我们想投这儿"。

### 1.3 有没有地理约束？

地铁能直达的乐园（迪士尼/海昌）可以做"廊道拦截"；乐高在金山没有地铁直达，做廊道拦截基本无效——这时只能做"家门口的曝光"（打有孩子的地方，不打去程）。

## 2. 目标人群该怎么定义

### 2.1 只能定义到「<20 岁」，这是数据决定的

赛题给的可视化平台数据，年龄只分两档：`<20` 和 `20–39`。所以：

- ✅ 可以说"面向 <20 岁人群及其家庭"
- ❌ 不能说"面向 5–12 岁核心客群"——你没有这个粒度的数据

**诚实说法**：「平台数据只到 <20 岁这一档，我们用它做目标人群口径。如果客户需要更细的年龄段，需要额外调研。」

### 2.2 但要知道「<20 岁」里的结构

| 子群 | 谁掏钱 | 投在哪 |
|---|---|---|
| 幼儿园/小学（3–12） | 家长 | 学校周边、亲子商圈、少年宫 |
| 初中（12–15） | 家长+自己 | 学校周边、地铁 |
| 高中（15–18） | 自己+家长 | 地铁、商圈 |
| 大学（18–20） | 自己 | 大学城、地铁 |

**乐高这类乐园的核心是 3–12 岁 + 陪同家长**，所以「儿童医院/少年宫/亲子社区」的权重应该高于「大学城」。这一点在 POI 库的 `u20Weight` 里已经体现了（少年宫 0.68 > 公立学校 0.62 > 科技馆 0.42）。

---

## 3. 五种人群聚集点的商业含义

| 类型 | 为什么值钱 | 坑 |
|---|---|---|
| **科技馆/博物馆** | 节假日单日客流上万，浓度+集中度双高，小预算最优 | 全上海就十几个，很快买空 |
| **少年宫** | <20 岁浓度最高（0.68），课后周末刚性聚集 | 单点容量有限，要分散买 |
| **儿童医院** | 陪同家长浓度最高（0.52 > 孩子 0.35），**打的是掏钱的人** | 场景敏感，文案要克制，别做促销感 |
| **私立学校** | 客单价高的亲子家庭 | 数量中等（32 个），200–300 万才铺得开 |
| **公立学校** | 数量极多（900），能形成面 | 单点容量小，浓度不差但需要大预算才有效果 |
| **亲子社区/商圈** | 兜底盘，哪里不够补哪里 | 浓度最低（0.20），效率最差 |

**一句话总结这套逻辑**：
> 钱少 → 买浓度（科技馆/少年宫）；钱多 → 买规模（公立学校）；中间 → 买客单价（私立学校/儿童医院）。

## 4. 合规红线（这个不能错）

| ❌ 不能说 | ✅ 应该说 |
|---|---|
| 在学校里投广告 | 在学校**周边 300–500 米**的地铁口/公交站/社区点位投 |
| 在校园内做推广 | 在校园**周边通学动线**上做曝光 |
| 和学校合作投放 | 覆盖学校**周边**的亲子家庭 |

**为什么**：中小学/幼儿园校内商业广告有明确限制（教育部门+市场监管）。但"学校周边的地铁站"是完全正常的户外媒体点位——同一批人、同一时段，合法。

**这一条写进 skill 是因为它是最容易被评委/客户抓的硬伤，而措辞差别极小。**

## 5. 从需求到策略：一份决策树

```
拿到 brief
├─ 客户要精准还是覆盖？
│  ├─ 精准 → precision，先跑，看预算能否吸收
│  │         └─ 吸收不了（<85%）→ 升级到 balanced，并说明"精准点位已买满"
│  └─ 覆盖 → reach
├─ 预算规模？
│  ├─ ≤100 万 → precision/balanced（科技馆+少年宫+儿童医院）
│  ├─ 200–300 万 → balanced（+私立学校）
│  └─ ≥400 万 → reach（+公立学校+大流量枢纽）
├─ 目的地有地铁直达吗？
│  ├─ 有 → 可加 corridor 策略比较
│  └─ 没有（乐高）→ 不做廊道，主做"家门口曝光"
└─ 输出：至少 2 个方案的对比 + 适用场景
```

## 6. 怎么判断一个方案"好不好"

不要只看曝光总量。四个维度一起看：

| 维度 | 指标 | 好的标准 |
|---|---|---|
| **覆盖** | `targetReach` | 越大越好 |
| **效率** | `efficiency`（每万元目标曝光） | 用于跨预算比较 |
| **浓度** | `targetShare`（目标人群占比） | 越高说明买得越准 |
| **可执行** | `utilization` | ≥85% 才算"钱花出去了" |

**这四个会互相打架**，这就是为什么需要你来做判断，而不是模型直接输出"最优解"。

举一个真实的权衡：
- `precision` 的 targetShare 最高（浓度最纯），但 utilization 可能只有 16%
- `reach` 的 targetReach 最高（覆盖最广），但 targetShare 会掉下来

**你的工作是把这两个方案的取舍说清楚，让客户选。**

## 7. 三个必须能脱口而出的解释

### 7.1 「为什么 100 万投科技馆，500 万投公立学校？」

> 「科技馆全上海就十几个，人流量集中，100 万就能买满，效率最高。但买满之后就没货了——500 万如果还投科技馆，钱根本花不出去。这时候只能往公立学校（900 所）这种数量多的点位铺，用广度换规模。所以不是我们想投公立学校，是预算逼着我们往下溢出。」

### 7.2 「<20 岁人群怎么打？孩子又不掏钱。」

> 「打的是两个：孩子（引发想去）+ 陪同家长（掏钱）。所以儿童医院这类点位特别值钱——它的家长浓度（0.52）比孩子（0.35）还高，是纯粹的决策者场景。」

### 7.3 「投学校合规吗？」

> 「我们不投校内。投的是学校**周边 300–500 米**的地铁口和公交站，这是正常的户外媒体点位，同一批家庭、同一个通勤时段，完全合规。」

## 8. 这个 skill 的输出物

不是一个方案，是**一份策略说明**：

1. **这一单的判断**：精准还是覆盖？为什么？
2. **推荐的策略组合**：跑哪 2–4 个策略，各自代表什么主张
3. **库存约束的说明**：预算到哪个量级会遇到什么天花板
4. **合规口径**：涉及学校时必须用"周边"表述
5. **交给下游**：把策略参数传给 [计算模型 skill](./投放方案计算与比选.md)
