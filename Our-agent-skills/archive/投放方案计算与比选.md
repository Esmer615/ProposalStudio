# Skill · 投放方案计算与比选

> 版本 **v1.3** ｜ 归属：新云媒介提案台 ｜ 对应 PRD 第 4.3–4.8 节
> 这是给 **Agent** 用的技能说明书，不是给人看的教程。

---

## 0. 这个 skill 解决什么问题

**你不直接"想"出一个方案，你先设计几个方案，再让计算模型算，然后比较。**

原因：投放这事一旦算错就是商业事故（报错价、超卖库存）。所以：

- **模型负责算**：库存核对、组合、报价、曝光量 —— 全是确定性规则，同样输入必得同样输出
- **你负责想**：这一单该走"精准"还是"广度"？预算给到 500 万值不值？哪几个策略值得试？

你的核心动作是 **`compare`**：一次提交多个策略，拿到可比的结果，再说人话。

## 2. 四个内置策略（你的起点，不是终点）

策略的差别只有一个参数：**浓度指数**（决定「要多准」还是「要多广」）。

```
效率 = 曝光 × 浓度^指数 ÷ 单价
```

| 策略 | 指数 | 行为 | 什么时候用 |
|---|---|---|---|
| `precision` 精准优先 | **3.0** | 浓度稍有稀释就掉队，钱只砸在最浓的点上 | 客户要"每一分钱都贴在目标人群上" |
| `balanced` 均衡覆盖 | **1.5** | 浓度和量各占一半 | 常规单，两头兼顾 |
| `reach` 广度触达 | **0.3** | 几乎只看量，浓度仅微调 | 客户要曝光量、老板要看数字 |
| `corridor` 廊道拦截 | 0.5 + 廊道加成 | 沿动线拦截 | 有地铁直达的乐园（迪士尼/海昌），**不适用乐高** |

### 2.1 铁律：预算一定花满（v1.2 修正，务必理解）

**「优先买什么」≠「只能买什么」。** 预算花不完 = 客户的钱被浪费。

引擎的三轮兜底保证预算花满：

| 轮次 | 做什么 | 什么时候触发 |
|---|---|---|
| R1 | 纯效率贪心，同站点限购 | 总是 |
| R2 | 放开媒介配比，钱往有货的地方倒 | 预算 <95% 时 |
| R3 | 放开复购（最多 2 倍），把最后的钱花掉 | 预算仍 <95% 时 |

**实测：四个策略在 100/200/300/500 万下全部花满 100%。**

只有一种情况钱花不完：**库存真的买空了**。这时 `metrics.absorbed=false`，必须如实报。

### 2.2 一个必须知道的事实：科技馆买不满 100 万

| POI 类型 | 全上海 | 周边有货点位 | 大约买满需要 |
|---|---|---|---|
| 科技馆/博物馆 | 14 个 | **22 个点位** | **约 40–50 万** |
| 少年宫 | 16 个 | 13 个点位 | 约 30 万 |
| 儿童医院 | 9 个 | 10 个点位 | 约 25 万 |
| 亲子社区 | 120 个 | 40 个点位 | 约 100 万 |
| 公立学校 | 900 个 | 13 个点位 | 约 25 万（代表性重点校）|

**所以 100 万预算，光投科技馆是花不完的——必然溢出到儿童医院、少年宫、亲子社区。**

这不是策略失效，这恰恰是「分档」逻辑的真实起点：**溢出比预想的更早，50 万左右就开始了。**

## 3. 数据来源（务必分清，答辩会被问）

### 3.1 POI 推算（当前默认）

`pois.json` 里有 112 个人群聚集点，按类型半径（学校 400–500m、场馆 900m）算每个媒体点位的 `<20 岁浓度`。

- 标签：`audienceSource = "poi_estimate"`
- **这是估算，不能当实测宣传**

### 3.2 可视化平台数据（优先级更高，你们要接的就是这个）

传入 `regionTraffic` 即可，模型会自动切到平台口径：

```jsonc
"regionTraffic": [
  {
    "name": "人民广场",
    "lng": 121.4737, "lat": 31.2304, "radius": 1500,
    "total": 4860000,
    "ageBands": { "0-19": 486000, "20-39": 2332800, "40-59": 1458000 },
    "month": "2023-10"     // 平台指定的 2023 年月份
  }
]
```

覆盖到的点位 `audienceSource` 会变成 `"platform"`，`dataQuality.trafficSource` 变成 `platform` 或 `mixed`。

**你必须在输出里区分这两种来源** —— 见第 6 节话术。

## 5. 遇到这些 warning 你怎么处理

| warning code | 含义 | 你该怎么做 |
|---|---|---|
| `budget_underused` | 预算只花了 <85%，点位不够 | **必须告诉用户**，并给出两个选择：放宽策略 / 降低预算并说明理由。**不要假装花完了。** |
| `filler_dominant` | 补量占比 >50%，浓度被摊薄 | 如实告诉客户"多少钱花在重点点位、多少钱用来铺量" |

## 6. 输出的四条硬规矩

### 规矩 1：先说「花满了没有」，再说「买得准不准」

v1.2 之后**预算一定会花满**（三轮兜底），所以重点不是"花没花完"，而是**"纯度多高"**。

> ❌ 「本方案 200 万，覆盖 601 万人次」
> ✅ 「本方案 200 万全部用掉。总曝光 1,908 万人次，其中 <20 岁目标人群 601 万（POI 估算口径），纯度 32%。」

**只有一种情况要报"没花完"**：`metrics.absorbed === false`，说明库存真的买空了。这时必须如实说：
> 「这单 500 万，但全市符合条件的有货点位已经买满，只花得掉 X 万。剩下的建议留到下一波档期，或者放开目标人群口径。」

### 规矩 2：区分「平台实测」和「POI 估算」

> ❌ 「目标人群触达 601 万人次」
> ✅ 「目标人群触达 601 万人次（POI 估算口径，非平台实测）」

如果 `dataQuality.trafficSource === "poi_estimate"`，每次报数字都要带这个尾巴。

### 规矩 3：比较方案时，先说口径再说结论

> ✅ 「三个方案都是同一笔 200 万，全部花满。按目标曝光总量排：广度 601 万 > 均衡 467 万 > 精准 467 万。
> 但精准的纯度是 32%，广度也是 32%——200 万这个量级，三者的纯度已经趋同了，因为好点位就那么多。**预算越大，策略差异越小。**」

### 规矩 4：不要给单一的「最优解」

你的价值是**呈现权衡**，不是替客户拍板。至少给两个方案的对比 + 各自适合什么情况。

## 7. 标准工作流（照这个走）

```
1. 读需求 → 判断行业/场地/预算/媒介/档期
2. 用 compare 跑 3–4 个策略（不要只跑一个）
3. 检查每个方案的 utilization 和 warnings
   ├─ 有 budget_underused → 该方案不能直接推荐
   └─ 全部 absorbed → 可直接横向比
4. 按 targetReach 排序，挑出 top2
5. 读 top2 的 picks，看它们分别买了什么地方（这才是"策略差异"的体现）
6. 输出：口径 + 对比 + 两个方案的适用场景 + 你的建议
```

## 8. 一个完整示例（照着改）

**输入**
```json
{
  "industry": "park", "focusId": "legoland",
  "budget": 2000000, "weeks": 4,
  "mediaKinds": ["bus", "metro"],
  "compare": ["precision", "balanced", "reach"]
}
```

**模型返回（简化）**
```
#1 广度触达  目标曝光 549w  花掉 199.8w (100%)  纯度 49%
#2 廊道拦截  目标曝光 426w  花掉 200.0w (100%)  纯度 42%
#3 均衡覆盖  目标曝光 322w  花掉 199.9w (100%)  纯度 38%
#4 精准优先  目标曝光 178w  花掉 200.0w (100%)  纯度 25%
```

**你该这么说**

> 「200 万这单，四个方案都把钱花满了——**这是前提，不花满就是浪费**。
>
> 区别在哪？花在重点点位的比例：精准策略 27% 的钱砸在科技馆/少年宫/儿童医院这类高浓度点上，广度策略只有 15%。所以精准的纯度是 25%……等等，这里精准的纯度反而最低？
>
> 因为精准只认三类 POI 选点，买到的却是全上海的高浓度点位——统计口径是统一的。所以给客户的建议是：**要曝光量走广度（549 万），要"每一分钱都贴高浓度点位"走精准（27% 预算在重点点位）**。
>
> 注：以上曝光为 POI 估算口径，接入可视化平台区域人流后，我们会用平台实测数据替换。」

## 9. 你不能做的事

| 禁止 | 原因 |
|---|---|
| 编一个人流量数字 | 只能用 pois.json 的估算或 regionTraffic 的平台数据 |
| 声称"预计带来 X 人到园" | 户外广告没有转化归因，只能算曝光 |
| 在预算花不完时假装花完了 | 违反规矩 1，是最严重的问题 |
| 只给一个方案说"这是最优" | 你的价值是呈现权衡 |
| 说"投在学校里" | 合规红线。只能说"学校周边 300–500 米的地铁/公交点位" |
