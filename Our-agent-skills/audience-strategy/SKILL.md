# 想策略：这一单值得跑哪几个场景

## 0. 先纠正一个事实

旧版 skill 里写的 `precision / balanced / reach / corridor` 是上一个 JS 原型的**策略参数**。
**当前 Python 引擎没有这四个参数**。引擎是一个 CP-SAT 确定性优化器，目标函数固定，
通过约束（预算、库存、媒介配比、等级、线路数、施工产能、锁定）求解。

所以不要再说“跑四个策略比一比”。正确做法是：

> 用引擎真正支持的**场景轴**做对比：预算、媒体组合、档期、周数、客户类型、锁定。
> “精准 vs 覆盖”是**分析视角**，通过 objective 影响场景选择与评分权重，并在话术里说明。

这是答辩时能站住的说法：**不假装有策略参数，只用真实可复算的输入做敏感性分析。**

---

## 1. 先判断这一单要回答什么问题

| 客户说法 | 真实问题 | 该设计的场景 |
|---|---|---|
| “要触达目标人群” | 买得准不准 | 基准 + 媒体组合参考 + 预算下探 |
| “要让全上海看到” | 覆盖能到多大 | 基准 + 预算上探 + 弹性拐点 |
| “预算就这么多，怎么花最值” | 边际效率 | 基准 + 预算下探 + 拐点 |
| “老板要看曝光量” | 数字与代价 | 基准 + 上探，但必须说频次/浓度代价 |
| “先看看，还没定” | 不确定性 | 基准 + 上下探，给区间而不是单点 |

objective 不是引擎参数，是**分析视角**：`balanced / reach / precision / efficiency / brand`。

---

## 2. 目标人群只能定义到「<20 岁」这一档

赛题/当前数据没有更细年龄段。可以说：

- ✅ “面向 <20 岁人群及其家庭”
- ❌ “面向 5–12 岁核心客群”（没有这个粒度的数据）

当前构建甚至没有接入可视化平台区域人流；目标人群是**场馆档案的策划口径**
（乐高 250 万，迪士尼/海昌各 250 万），不是实测去重人群。话术必须标“策划假设”。

### <20 岁里的结构（用于选点，不用于声称数据粒度）

| 子群 | 谁掏钱 | 该投哪 |
|---|---|---|
| 幼儿园/小学（3–12） | 家长 | 学校周边、亲子商场、少年宫、儿童医院 |
| 初中（12–15） | 家长+自己 | 学校周边、地铁 |
| 高中（15–18） | 自己+家长 | 地铁、商圈 |
| 大学（18–20） | 自己 | 大学城、地铁 |

乐高的核心是 3–12 岁 + 陪同家长，所以「亲子商场 / 科技馆 / 少年宫 / 儿童医院」
的权重应高于「大学城」。但**不要自己编权重**：权重在
`data/config/venues/*.json` 的 `poi_type_weights` 里，引擎已经用了。

## 3. 场馆交通结构决定媒体角色

| 场馆 | 地铁直达 | 主结构 | 媒体含义 |
|---|---|---|---|
| 乐高（金山枫泾） | 否 | 自驾 68% / 高铁 14% | 公交做社区广度，地铁做家庭出发枢纽；不要做“地铁廊道拦截” |
| 迪士尼 | 是（11 号线） | 地铁/自驾 | 可做廊道拦截 + 枢纽 |
| 海昌 | 是（16 号线+短驳） | 地铁/自驾 | 同上，注意滴水湖距离 |

**同一个行业，交通结构不同就是两套打法。** 场景设计时用
`catalog.venue_profiles[venue].metro_direct` 判断，不要凭印象。

## 4. 预算与供给：用弹性，不要背死数字

旧版 skill 里有一张“科技馆 22 个点位、约 40–50 万买满”的表。那是上一个原型的观察，
**当前库存快照与候选池已经变了**，不要原样引用。

正确做法：

1. 先跑基准方案，看 `quote.total_paid_wan / inputs.budget_wan`。
2. 跑九档弹性，看 `knee_budget_wan`（Reach 达到最高值 98% 的预算）。
3. 用 `coverage.poi_hits` 和 `plan.summary` 说明“钱花到了哪些类型/区县”。
4. 如果预算使用率 <85%，说明供给天花板已到，不要假装花满。

**分档逻辑仍然成立**，但要用本次数据说话：

> 钱少 → 先买高浓度点位；钱多 → 必须向更广的点位溢出。
> 溢出不是策略选择，是库存约束；在提案里要讲成“分档”，不是“我们想投这儿”。

## 5. 场景设计规则（默认最多 4 个）

必选：

1. **base**：客户原始需求，作为所有对比的基准。

按 objective 优先级补充：

- `efficiency`：预算下探 → 弹性拐点 → 预算上探
- `reach` / `brand`：预算上探 → 弹性拐点 → 预算下探
- `precision` / `balanced`：预算下探 → 预算上探 → 弹性拐点

媒体轴：

- 客户选了两者 → 加一个单媒体参考（乐高默认公交-only；迪士尼/海昌按 objective 选地铁或公交）
- 客户只选了一个 → 加一个“补上另一种媒体”的参考

约束：

- 预算必须在 100–500 万；不重复、不越过边界。
- `quick` 模式只跑 base + 弹性。
- 每个场景都要能回答一句“这个场景检验什么”，写进 `intent`。

## 6. 合规措辞（最容易翻车的地方）

| ❌ 不能说 | ✅ 应该说 |
|---|---|
| 在学校里投广告 | 在学校**周边 300–500 米**的地铁口/公交站/社区点位投 |
| 在校园内做推广 | 在校园**周边通学动线**上做曝光 |
| 和学校合作投放 | 覆盖学校**周边**的亲子家庭 |

中小学/幼儿园校内商业广告有明确限制；学校周边的户外点位是正常媒体。
同一批人、同一时段，合法。**措辞差别极小，但这是硬伤。**
