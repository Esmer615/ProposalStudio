# 合规措辞（audience-strategy 参考）

## 学校

| ❌ | ✅ |
|---|---|
| 在学校里投广告 | 在学校**周边 300–500 米**的地铁口/公交站/社区点位投 |
| 在校园内做推广 | 在校园**周边通学动线**上做曝光 |
| 和学校合作投放 | 覆盖学校**周边**的亲子家庭 |

原因：中小学/幼儿园校内商业广告有明确限制（教育部门 + 市场监管）。
学校周边的地铁站/公交站是正常户外媒体点位，同一批人、同一时段，合法。

## 效果承诺

| ❌ | ✅ |
|---|---|
| 保证入园 X 人 | 提升目标人群曝光/认知，不承诺到园人数 |
| ROI 做到 X | 每万元买到 X 人次目标曝光 |
| 转化率 X% | 户外没有归因链路，不给转化率 |
| 包入园 | 删除；改为监测报告 + 曝光估算 |

## 数据表述

| ❌ | ✅ |
|---|---|
| 触达 287 万人（无口径） | 目标人群 Reach X%（模型估算） |
| 全上海都能看到 | 覆盖 X 个区县 / Y 个 POI，总曝光 Z 万人次（模型估算） |
| 100% 花满 | 预算使用率 X%，剩余 Y 万 |
| 精准策略/广度策略 | 预算下探/上探/媒体组合参考 |

## 儿童场景

儿童医院/妇幼/亲子商场可以投，但文案要克制：
- 不做促销感、不做医疗功效暗示。
- 不出现“保证孩子喜欢”“必去”等绝对化表述。
- 优先讲“家庭出游的一天”“周末亲子计划”这类场景。
