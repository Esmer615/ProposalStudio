# 承诺与口径指南（proposal-narrative 参考）

## 1. 可以说的

- 目标人群 Reach X%（模型估算）
- 总曝光 X 万人次（模型估算）
- 频次 X 次（模型估算）
- 混合 CPM X 元（媒体净价口径）
- 命中 X 个亲子/家庭 POI（公开近似）
- 覆盖 X 个区县 / X 条公交线 / X 个地铁口
- 预算使用率 X%，剩余 Y 万
- 刊例 X 万，落 X% 档，折后媒体费 Y 万
- 夜间施工 X 批，雨备 2 夜，误一补二

## 2. 不能说的

| 不能说 | 原因 | 改成 |
|---|---|---|
| 保证到园/入园 X 人 | 户外无归因 | 提升目标人群曝光/认知 |
| 销量/收益承诺 | 无数据支撑 | 不承诺；只讲曝光产出 |
| ROI / 投资回报 | 不是财务指标 | 每万元目标曝光 |
| 转化率 X% | 无点击/归因链路 | 不给 |
| 投在校内 | 合规红线 | 学校周边 300–500 米 |
| 全上海都能看到 | 夸大 | 覆盖 X 个区县/POI，曝光 Y 万人次（模型估算） |
| 预算一定花满 | 与当前引擎不符 | 使用率 X%，剩余 Y 万 |
| 精准/广度/廊道策略 | 当前引擎没有该参数 | 预算下探/上探/媒体组合参考 |
| 这是最优方案 | 抹杀权衡 | 两个方案分别适合… |
| AI 生成的方案 | 暗示不可控 | 规则引擎计算 + AI 解释 |

## 3. 主动披露清单

每次提案至少说一次：

1. 曝光/Reach/频次/CPM 是模型估算，不是实测。
2. 当前未接入可视化平台实测区域人流。
3. POI 坐标为公开近似，不用于测量级结论。
4. 目标人群基数是场馆档案策划假设，不是实测去重人群。
5. 折扣是区间化/落档口径，待赞助方确认。
6. 库存是红豆快照，上刊前需重核。
7. 不承诺到园人数、销量、财务 ROI。
8. 不投校内，学校相关统一说“周边 300–500 米”。

## 4. 被追问时的三层回答

> 「库存和刊例——红豆快照，数据版本 X；
> 人群/POI——公开近似，策划假设；
> 曝光/Reach——引擎饱和曲线模型估算。
> 每一层都能指到原始字段，哪一层你想细问？」

## 5. 儿童/学校场景

- 不出现“保证孩子喜欢”“必去”“最值”等绝对化表述。
- 儿童医院/妇幼不做医疗功效暗示。
- 学校相关只讲“周边 300–500 米的通学动线/地铁/公交点位”。
